Using the equivalent: loads and maximum power

Overview 1 · The big idea 2 · Finding Vth and Rth 3 · Loads and power

Once you have Vth and Rth, attaching a load RL is a two-resistor problem. The reason to build the equivalent is that you only do the hard analysis once, then answer every “what if the load changes?” question in one line.

The loaded equivalent

Vth and Rth are in series, and the load closes the loop. Everything follows from Ohm's law:

IL = Vth / (Rth + RL) VL = IL · RL = Vth · RL / (Rth + RL) PL = IL² · RL = Vth² · RL / (Rth + RL)²

These are just the voltage-divider and power formulas, now with the whole network collapsed into two symbols. Attaching a load never changes Vth or Rth — that is the point of building the equivalent.

Two things to notice. The open-circuit case (RL → ∞) shows VL = Vth, which is where Vth came from. And the power peaks in the middle of the table, not at either end.

Maximum power transfer

Treat PL as a function of RL and find its maximum. Setting the derivative to zero gives a very clean result:

Maximum power is delivered to the load when RL = Rth. At that match,

Pmax = Vth² / (4 Rth)

and the load voltage is exactly half of Vth.

For Example A: RL = 2.4 Ω gives Pmax = (4.8)² / (4 × 2.4) = 23.04 / 9.6 = 2.4 W, matching the middle row. Half the source power goes to the load and half is dissipated in Rth.

Maximum power is not maximum efficiency

Be careful with the phrase. At the match, the load receives half the power the source provides — the other half is lost in Rth, so the efficiency is only 50%. This is the right design goal when the source is weak and you must extract every microwatt (an antenna, a sensor, a radio receiver). It is the wrong goal for a power system, where wasting half the generated power would be unacceptable; there you want RL large compared with Rth so that nearly all the power reaches the load.

Check yourself

For Example A, what load resistance wastes the most power, and what is the efficiency then?

Maximum waste in Rth happens at the same match, RL = Rth = 2.4 Ω. Both resistors then carry 1 A and dissipate 2.4 W each, so the source delivers 4.8 W total and the efficiency is 50% — the worst case for a power supply.

You attach a load much larger than Rth. What happens to the terminal voltage and the power?

The terminal voltage rises toward Vth (little drop across Rth), but the current falls, so the power also falls — the load is not matched, so it extracts less than Pmax. Efficiency, however, is high: nearly all the source power reaches the load. Large RL is good for efficiency, poor for power transfer.
